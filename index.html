Setup

Ollama

  1. Install from ollama.com and download a model, e.g. ollama pull qwen3:8b (7–8B models or larger work best for planning and email).
  2. Allow this site to talk to Ollama by setting OLLAMA_ORIGINS to , then restart Ollama.
    Mac: launchctl setenv OLLAMA_ORIGINS "" · Windows: add it under System → Environment Variables · Linux: OLLAMA_ORIGINS= ollama serve

LM Studio

  1. Load a model, open the Developer tab and start the server.
  2. Turn on Enable CORS in the server settings.

If your browser asks to let this site access devices on your local network, allow it.

A small model downloads once into this browser and runs on your graphics card — fully private, and it works offline afterwards. Needs Chrome or Edge with WebGPU. Answers are simpler than cloud models.


Google — Gmail & Calendar

Optional. Lets Aide read and triage your inbox, save reply drafts, move spam, and sync Google Calendar.


How to get a Client ID (about 5 minutes)
  1. Open Google Cloud Console and create a project.
  2. Under APIs & Services → Library, enable the Gmail API and Google Calendar API.
  3. Under OAuth consent screen, choose External, fill in the app name and your email, and add yourself as a test user.
  4. Under Credentials → Create credentials → OAuth client ID, pick Web application and add this site's address as an Authorized JavaScript origin:
  5. Copy the Client ID here and click Connect.

While the app is in "Testing" mode only the test users you add can sign in — perfect for personal use. Sign-in lasts about an hour per session; Aide asks again when needed.
